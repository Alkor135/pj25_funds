# pj25_funds
Проверка стратегии хедж-фондов

## Окружение Python

Зависимости проекта устанавливаются в локальную папку `.venv`. После
переустановки Windows окружение необходимо пересоздать: оно содержит путь
к базовому Python и не переносится между установками системы.

Команды PowerShell из корня проекта (для установленного Python 3.14):

```powershell
& 'C:\Python\Python314\python.exe' -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
& .\.venv\Scripts\python.exe -m pip check
```

Если существующее окружение повреждено, предварительно переименуйте `.venv`
в свободную резервную папку, затем выполните команды выше. При восстановлении
5 октября 2026 года старое окружение было сохранено в `venv.bak`, а новое создано
на Python 3.14.8 с версиями пакетов из `requirements.txt`.
После переноса предыдущей реализации резервное окружение находится в
`old/scripts/venv.bak`; рабочая `.venv` остаётся в корне проекта.

В `.vscode/settings.json` интерпретатором по умолчанию для проекта задан
`.venv\Scripts\python.exe`. Если VS Code сохраняет ранее выбранный
интерпретатор, выполните `Python: Select Interpreter` через `Ctrl+Shift+P`
и выберите этот файл. После смены окружения откройте новый терминал.

## Транскрибация YouTube — `transcript.py`

Скрипт получает существующие субтитры видео через `youtube-transcript-api`,
сначала ищет русский язык, затем английский, объединяет реплики переводами
строк и сохраняет текст в UTF-8. Для работы требуется доступ к YouTube и
доступные субтитры у выбранного видео.

Параметры задаются переменными внутри `transcript.py`:

- `video_id` — идентификатор видео; текущее значение: `Z-hU97WO30I`.
- `languages` в вызове `yta.fetch()` — приоритет языков: `["ru", "en"]`.
- `file_output` — путь к выходному файлу; текущее значение: `quant_funds_2.txt`.
  Относительный путь отсчитывается от текущей рабочей папки; существующий
  файл перезаписывается после успешного получения субтитров.

Пример запуска из корня проекта без активации окружения:

```powershell
& .\.venv\Scripts\python.exe .\transcript.py
```

Аргументы командной строки скрипт не принимает. Это получение готовых
субтитров, а не распознавание речи из аудиодорожки.
