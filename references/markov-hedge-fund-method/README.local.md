# Локальная копия upstream-материалов

Источник: https://github.com/jackson-video-resources/markov-hedge-fund-method

Эта папка содержит справочные файлы из репозитория к видео. Они сохранены как внешний материал для анализа и сравнения, а не как финальная реализация проекта.

## Скачанные файлы

| Файл | Назначение |
|---|---|
| `README.md` | Общее описание метода и состава upstream-проекта |
| `markov-hedge-fund-method.md` | Исходный onboarding prompt из видео |
| `scripts/markov_regime.py` | Основной Python-скрипт upstream с MM/HMM и walk-forward |
| `skills/regime/SKILL.md` | Контракт skill и JSON-вывода |
| `pine-script/markov-hedge-fund-method.pine` | TradingView-индикатор |

Собственные формализованные правила проекта находятся в `docs/strategy_markov_hedge_fund_method.md`.
